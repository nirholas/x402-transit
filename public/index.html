x402 Transit

Transit trip planning and live delay snapshots from open GTFS feeds, priced per query. The feed is called live — an unreachable feed returns 502 rather than invented arrival times.

Paid routes answer an unpaid request with HTTP 402 and a challenge listing both payment rails. Pay in USDC on Base or Solana — your client picks — and the same request returns the data. There is nothing to sign up for.

Try it

BASE=http://localhost:4024

# Unpaid: the 402 challenge, including how to call the route and what comes back
curl "$BASE/delays?stopId=<stop>"

# Paid: x402-fetch wraps a wallet around fetch and retries automatically
npm i x402-fetch viem

For agents

  • /openapi.json — OpenAPI 3.1, every route, parameter and response schema.
  • /.well-known/x402 — the machine-readable price sheet, both rails.
  • Every 402 challenge carries accepts[].outputSchema: input is how to build the request, output is the JSON Schema of what you get after paying. One 402 is enough to call this API correctly.
